# Ilaria Bernardi — Portfolio

A responsive one-page computer science portfolio featuring the GT Movies Store Django project.

## Publish on GitHub Pages

1. On GitHub, create a **public** repository named `ibernardi1.github.io`.
2. Upload every file and folder from this folder to the repository. Keep `_next`, `.nojekyll`, and `index.html` exactly where they are.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**. Select `main` and `/ (root)`, then save.
5. After GitHub finishes publishing, visit `https://ibernardi1.github.io`.

## Before submitting the assignment

- Record the GT Movies Store demo and upload it to YouTube, Vimeo, or Google Drive.
- Replace the clearly marked demo-video placeholder on the page with the final video embed or link.
- Confirm that the GitHub profile link and project descriptions are accurate.
- Open the published page in a private browser window to confirm that your instructor can access it.

The site is already fully built. No package installation, paid service, or local build step is required to publish this folder.
