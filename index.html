02 — Featured project

GT Movies Store

A full-stack movie storefront built with Django, connecting a browsable catalog to accounts, cart management, and a purchase flow.

01

The challenge

Make an end-to-end store feel simple.

The project brings multiple systems together behind one coherent journey. A user can discover a title, learn more, create an account, build a cart, understand the total, and complete the flow without losing context.

User-story coverage

Requirements translated into working behavior.

  • Browse a catalog of available movies
  • Open a movie to view its full details
  • Create an account and sign in
  • Add selected titles to a shopping cart
  • Review the total and remove unwanted items
  • Complete the purchase flow
03 — Process & methodology

How I built
the project.

I used the textbook as a structured guide and worked iteratively, completing and testing one feature before moving to the next.

My methodology

Build one feature at a time.

I followed Django 5 for the Impatient chapter by chapter. I first created the project structure, URLs, views, templates, and shared layout. Then I added database models, authentication, reviews, the shopping cart, orders, and deployment. I tested each feature before continuing so problems stayed small and easier to understand.

Questions & doubts

Read the error and isolate the cause.

When something did not work, I read the Django traceback, identified whether the problem came from a URL, view, template, model, or setting, and changed one thing at a time. I compared my work with the textbook example and consulted documentation when I needed more context.

Finishing the project: I used Git and GitHub to preserve my progress, then configured and deployed the application on PythonAnywhere. Deployment helped me understand how project paths, settings, static files, and the production environment fit together.
